# 실무 과제

### Q1. App.jsx가 "전체 좋아요 개수"를 알기 위해서는 state가 지금처럼 LikeCard 안에만 있어도 괜찮을까요?

아니라고 생각합니다. LikeCard 안에서만 state를 관리하면 App.jsx는 각 카드의 좋아요 상태와 전체 좋아요 개수를 알 수 없습니다.

### Q2. 만약 안 된다면, state는 어느 컴포넌트가 가지고 있어야 할까요?

전체 좋아요 개수를 관리해야 하는 부모 컴포넌트인 App.jsx가 state를 가지고 있어야 합니다.

### Q3. 그렇게 옮긴다면 LikeCard는 지금처럼 자기 state를 그대로 가지고 있어도 될까요?

아니라고 생각합니다. LikeCard는 App.jsx에서 전달받은 props를 화면에 출력하는 역할을 하고, state는 App.jsx에서 하나로 관리하는 것이 좋습니다. 이렇게 하면 모든 카드의 좋아요 상태를 부모 컴포넌트가 한 번에 관리할 수 있습니다.
